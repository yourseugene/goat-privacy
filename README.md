# Privacy Policy
Last updated: May 12, 2026

This Privacy Policy describes how the application "Goat Online" collects, uses, and protects user information.

Information Collection

The application does not intentionally collect personally identifiable information such as name, address, or payment information.

Technical Data

For the proper operation of online features, the application may process limited technical information, including:
- device type
- operating system version
- connection status
- crash logs and diagnostics

This information is used only to improve application stability and performance.

Online Gameplay

The application allows users to connect to online game servers. Server operators may process gameplay-related data necessary for multiplayer functionality.

Third-Party Services

The application may use third-party services such as:
- Apple services
- Firebase
- analytics or crash reporting tools

These services may collect technical diagnostic information according to their own privacy policies.

Data Sharing

The application does not sell personal information to third parties.

Children's Privacy

The application is not directed toward children under the age required by local laws without parental permission.

Security

Reasonable measures are taken to protect technical data and maintain service security.

Changes to This Policy

This Privacy Policy may be updated from time to time. Updated versions will be published at the same URL.
